# Course Creation Guide

This guide explains how to create a new course and keep it consistent with the Johnny.Decimal system and the site parser.

## 1. Choose an Area

Check `00.00 Master Index.md` to see which areas are already in use.

If all 10-number ranges are full, extend the system by creating a new range (for example `100-109`) and update the master index.

## 2. Create the Folder Structure

Create a folder named:

```
[Area] Great Literature [ID] - [Course Name]/
```

Example:

```
30-39 Great Literature 103 - Poetry/
```

Inside, create these folders:

```
[Area] Great Literature [ID] - [Course Name]/
├── [Area] Management/
│   ├── [Area].00 Index.md
│   └── [Area].01 Syllabus.md
├── [Area+1] Books/ (or Poetry, Stories, etc.)
├── [Area+2] Supplemental Readings/
├── [Area+3] Resources/
└── [Area+4] Notes and Reflections/
```

Standard categories:

- **X1:** Primary materials (Books, Poetry Collections, etc.)
- **X2:** Supplemental Readings
- **X3:** Resources
- **X4:** Notes and Reflections
- **X5–X9:** Reserved for course-specific needs

## 3. Add Management Documents

Create the following in the management folder:

- `[Area].00 Index.md`
- `[Area].01 Syllabus.md`

Include required frontmatter (see `FORMAT.md`).

## 4. Add Books and Guides

For each book or collection:

1. Create a folder: `[ID].XX [Title] - [Author]/`
2. Add `Book Metadata.md` with required frontmatter.
3. Copy the three guide templates and remove `_TEMPLATE` from the filenames.
4. Fill in content.
5. Update the course index.

## 5. Update the Master Index

Edit `00-09 Templates and Resources/00 System Management/00.00 Master Index.md`:

- Add the course to the active list.
- Mark the area as in use.
- Link to the syllabus.

## 6. Validate

From the `site/` directory:

```bash
npm run validate
```

Fix any frontmatter errors before syncing or deploying.

## Course Type Notes

- Poetry: change “Chapter” to “Poem” or “Section.”
- Short stories: “Story-by-Story” works well.
- Regional or genre courses: add context sections in guides or resources.
