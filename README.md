## 🗂️ Organization System

This collection uses the **Johnny.Decimal** system for organization:

- **Areas (00-99):** Major collections (each course gets its own area)
- **Categories (X1-X9):** Types of materials within each area
- **IDs (.01-.99):** Individual items within categories

### Current Structure

```
Literature/
├── 00-09 Templates and Resources/ (shared templates)
├── 10-19 Literature 101/ (Literature 101)
├── 20-29 Literature 102/ (Science Fiction & Fantasy)
├── 30-39 Literature 103/ (Poetry)
├── [Future courses in 40-49, 50-59, etc.]
└── README.md (this file)
```

## 📋 Quick Start

1. **Choose a course** from the list above
2. **Navigate to the course folder** (e.g., `10-19 Literature 101/`)
3. **Check the course's `00 Index.md`** for the reading list
4. **Start with a book's `01 Pre-Reading Guide.md`** before reading
5. **Use `02 Chapter-by-Chapter Notes.md`** while reading
6. **Read `03 Post-Reading Analysis.md`** after finishing

---

## 🎯 Adding a New Course

Want to create a new course (e.g., Russian Literature, Poetry, etc.)?

1. **Check `00-09 Templates and Resources/00 Master Index.md`** for available areas
2. **Choose the next available area** (e.g., 30-39)
3. **Create the folder structure** following the standard pattern
4. **Copy templates** from `00-09 Templates and Resources/01 Study Guide Templates/`
5. **Update the master index**

See `00-09 Templates and Resources/00 Master Index.md` for detailed instructions.

## 📚 Study Guide System

Each book/item in every course follows a **three-part study guide system**:

1. **01 Pre-Reading Guide.md** - Read before starting
2. **02 Chapter-by-Chapter Notes.md** - Use while reading
3. **03 Post-Reading Analysis.md** - Read after finishing

Templates are available in `00-09 Templates and Resources/01 Study Guide Templates/`

## 📖 About Johnny.Decimal

This system uses [Johnny.Decimal](https://johnnydecimal.com/) for organization:
- Numbers stay in order (unlike alphabetical sorting)
- Easy to reference ("eleven oh one" = The Old Man and the Sea)
- Scales naturally as you add materials
- Clear, consistent structure
