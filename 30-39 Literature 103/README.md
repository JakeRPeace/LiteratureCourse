# Great Literature 103 - Folder Organization Guide

This folder uses the **Johnny.Decimal** system for organization. See `00 Index.md` for the complete catalog of all materials.

## Quick Start

- **Poetry Collections**: Look in `31 Poetry Collections/` folder
- **Additional Poems**: Will go in `32 Supplemental Readings/`
- **Resources**: Will go in `33 Resources/`
- **General notes**: Will go in `34 Notes and Reflections/`

## Adding a New Poet

1. Go to `31 Poetry Collections/` folder
2. Check `00 Index.md` for the next available number
3. Create folder: `31.XX [Collection Title] - [Poet Name]`
4. Copy the three templates from `00-09 Templates and Resources/01 Study Guide Templates/`:
   - `_TEMPLATE 01 Pre-Reading Guide.md`
   - `_TEMPLATE 02 Chapter-by-Chapter Notes.md` (adapt for poetry)
   - `_TEMPLATE 03 Post-Reading Analysis.md`
5. Adapt templates for poetry:
   - Change "Chapter" to "Poem" or organize by sections
   - Adjust questions to focus on poetic devices, form, imagery
   - Modify structure as needed
6. Fill in each template with poet-specific information
7. Update `00 Index.md` with the new entry

## Study Guide Structure

Each poet/collection folder should contain three documents following the same structure as other courses, but adapted for poetry:

- **01 Pre-Reading Guide.md** - Read before starting (overview, importance, what to think about)
- **02 Poem-by-Poem Notes.md** - Use while reading (important points and questions for each poem or section)
- **03 Post-Reading Analysis.md** - Read after finishing (in-depth exploration)

**Note:** The templates are designed for books but work well for poetry with minor adaptations. See the templates in `00-09 Templates and Resources/01 Study Guide Templates/` for the base structure.

## Adapting Templates for Poetry

When using the templates for poetry:

1. **Pre-Reading Guide:** Works as-is, just focus on poet instead of book
2. **Chapter-by-Chapter Notes:** 
   - Rename to "Poem-by-Poem Notes" or "Section-by-Section Notes"
   - Adjust structure for individual poems or poem groups
   - Focus on poetic devices, form, imagery, themes
3. **Post-Reading Analysis:**
   - Works well as-is
   - Add sections on poetic form, meter, rhyme scheme if relevant
   - Focus on how form serves meaning

## Why This System?

- **Numbers stay put**: Unlike alphabetical names, numbered folders maintain their position
- **Easy to find**: Quick mental reference ("thirty-one oh one" = Whitman)
- **Scales naturally**: Add poets in any order, system accommodates growth
- **Clear organization**: Each type of material has its own category
