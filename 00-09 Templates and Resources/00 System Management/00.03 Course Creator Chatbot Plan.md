# Course Creator Chatbot Plan

## Goal
- Let logged-in users create private courses with a chatbot.
- Start with a minimal “Add Test Course” button that inserts one course + one book into Supabase.

## Phase 0: MVP Insert Button (Now)
Deliverable:
- A UI button that inserts a user course and a single book for the current user.

Steps:
1. UI
   - Add a button on the Courses page (or a small admin panel) that is visible only when signed in.
2. Insert logic (client-side)
   - Use Supabase JS with the user session.
   - Insert into `courses` (source=`user`, owner_id=auth.uid()).
   - Insert a single book into `books`.
3. Verify
   - New course appears in the list immediately.
   - User course switcher includes the course.
   - Book appears in the user course page and status widgets work.

Suggested fields for the MVP insert:
- `courses`
  - `course_id`: `user-${userId}-${timestamp}`
  - `title`: “Test Course - Modern Literature”
  - `course_type`: “Modern Literature”
  - `summary`: short sentence
  - `slug`: slugify(title)
  - `source`: `user`
  - `owner_id`: current user id
- `books`
  - `book_id`: `${course_id}/book-01`
  - `course_id`: course_id
  - `category`: `01 Books`
  - `title`: “Test Book”
  - `author`: “Test Author”
  - `slug`: slugify(`${course_id}-book-01`)
  - `sort_order`: 1

## Phase 1: Guided Form (Pre-Chat)
Deliverable:
- A lightweight form that collects course title, type, summary, and 1–3 books.
- Validation and preview before insert.

## Phase 2: Chatbot MVP
Deliverable:
- Chat panel that captures intent + basic course details.
- Server-side function to parse chat into a structured payload.
- Create course + books from that payload.

## Phase 3: Full Chatbot + Draft Review
Deliverable:
- Draft builder with editable outline (course summary + reading list).
- Confirm + write flow with “Create Course” and “Cancel”.

## Risks / Notes
- Ensure RLS: user rows are private to owner_id.
- Keep user slugs unique per owner (already enforced).
- Avoid inserting `course_docs`/`book_guides` for MVP; add later.
