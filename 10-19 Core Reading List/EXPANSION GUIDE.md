# Expansion Guide - Adding Materials to Your System

This guide explains how to add new materials as your Great Literature 101 course grows.

---

## Adding a New Book

### Step-by-Step Process

1. **Check the Index**
   - Open `00 Index.md`
   - Find the last book number in Category 11
   - The next number is your new book's ID

2. **Create the Folder**
   - Go to `11 Books/` folder
   - Create: `11.XX [Book Title] - [Author Name]`
   - Use the next sequential number (currently 11.11)

3. **Create the Three Study Documents**
   - Copy templates from `00-09 Templates and Resources/01 Study Guide Templates/`:
     - `_TEMPLATE 01 Pre-Reading Guide.md` → rename to `01 Pre-Reading Guide.md`
     - `_TEMPLATE 02 Chapter-by-Chapter Notes.md` → rename to `02 Chapter-by-Chapter Notes.md`
     - `_TEMPLATE 03 Post-Reading Analysis.md` → rename to `03 Post-Reading Analysis.md`
   - Fill in each template with book-specific information

4. **Update the Index**
   - Add your new book to the "Current Books" list in `00 Index.md`
   - Update the "Last updated" date

5. **Study Guide Structure**
   Each book folder should contain three documents:
   - **01 Pre-Reading Guide.md** - Read before starting the book (overview, importance, what to think about)
   - **02 Chapter-by-Chapter Notes.md** - Use while reading (important points and questions for each chapter)
   - **03 Post-Reading Analysis.md** - Read after finishing (in-depth exploration of themes and meanings)

### Example

If you want to add *1984* by George Orwell:
- Next number: 11.11
- Folder name: `11.11 1984 - George Orwell`
- Create three files in that folder:
  - `01 Pre-Reading Guide.md` (copy from template)
  - `02 Chapter-by-Chapter Notes.md` (copy from template)
  - `03 Post-Reading Analysis.md` (copy from template)
- Add to index: `- **11.11** 1984 — George Orwell`

## Adding Supplemental Readings

### Short Stories or Essays

1. Go to `12 Supplemental Readings/`
2. Create folder: `12.XX [Title] - [Author]`
3. Start with 12.01, 12.02, etc.
4. Update `00 Index.md` under Category 12

### Examples
- `12.01 The Metamorphosis - Franz Kafka`
- `12.02 The Lottery - Shirley Jackson`
- `12.03 A Good Man is Hard to Find - Flannery O'Connor`

## What If You Exceed 99 Books?

If you somehow add more than 99 books to Category 11, you have options:

### Option 1: Start a New Category
- Use Category 16 (or any available 16-19)
- Continue numbering: `16.01 [Book] - [Author]`
- Update index to show both categories

### Option 2: Create a New Area
- Create `20-29 Extended Reading List/`
- Start fresh with `21 Books/` and `21.01`, etc.
- This keeps your core list separate from extended reading

### Option 3: Subdivide by Theme/Period
- Use multiple categories:
  - 11: Core Books (original 10)
  - 16: Additional Modernist Works
  - 17: Postmodern Works
  - 18: Contemporary Works
  - etc.

## Best Practices

### Naming Conventions
- Always include: `[ID] [Title] - [Author]`
- Keep titles consistent (use full titles, not abbreviations)
- Use proper capitalization

### Organization Within Folders
- Create subfolders if needed (e.g., `Quotes/`, `Chapters/`, `Analysis/`)
- Or use a single notes file - whatever works for you
- The template is just a starting point

### Keeping the Index Updated
- Update `00 Index.md` whenever you add something
- This is your master reference - keep it current
- The index helps you find things quickly

### Flexibility
- The system is designed to be flexible
- You can reorganize later if needed
- Numbers help maintain order, but you're not locked in
