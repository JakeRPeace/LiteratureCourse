# Repository Guidelines

## Project Structure & Module Organization
This repository is a curated set of literature course materials organized with the Johnny.Decimal system. Top-level folders are course “areas” like `10-19 Great Literature 101 - Modern Literature`. Each course follows a consistent internal layout:
- `X0 Management` for syllabi, indexes, and planning (for example, `10 Management/10.01 Syllabus.md`).
- `X1-X9` for course content such as books, study guides, and notes (for example, `11 Books/11.01 Title/02 Notes`).
- `00-09 Templates and Resources` holds shared templates and the master index.

## Build, Test, and Development Commands
This repo is documentation-only; there are no build or test commands. Use standard Markdown tooling if you want local previews (for example, a Markdown preview in your editor).

## Coding Style & Naming Conventions
- Use Markdown for all content.
- File and folder names follow Johnny.Decimal numbering: `NN.NN` for files and `NN Name` for folders.
- Keep titles in Title Case and match existing naming patterns (for example, `20.01 Syllabus.md`).
- Prefer short, directive headings and bullet lists for study guides.

## Testing Guidelines
There are no automated tests. Verify changes by opening the edited Markdown and checking links and table formatting.

## Commit & Pull Request Guidelines
- Commits in this repo use short, descriptive, present-tense messages (for example, `progress system`, `philosophy`).
- PRs should describe the course(s) affected, list new or moved materials, and link any updated syllabi or indexes.
- Include screenshots only if you changed rendered Markdown layouts (tables, diagrams).

## Content Quality Checklist
- Confirm new items appear in the relevant syllabus and/or index.
- Ensure numbering is unique and sequential within its section.
- Keep reading lists and study guides consistent with existing course tone.
