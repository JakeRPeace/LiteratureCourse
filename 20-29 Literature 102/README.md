# Great Literature 102 - Folder Organization Guide

This folder uses the **Johnny.Decimal** system for organization. See `00 Index.md` for the complete catalog of all materials.

## Quick Start

- **Books**: Look in `21 Books/` folder
- **Short stories/Essays**: Will go in `22 Supplemental Readings/`
- **Resources**: Will go in `23 Resources/`
- **General notes**: Will go in `24 Notes and Reflections/`

## Adding a New Book

1. Go to `21 Books/` folder
2. Check `00 Index.md` for the next available number
3. Create folder: `21.XX [Book Title] - [Author Name]`
4. Copy the three templates from the central location:
   - `00-09 Templates and Resources/01 Study Guide Templates/_TEMPLATE 01 Pre-Reading Guide.md`
   - `00-09 Templates and Resources/01 Study Guide Templates/_TEMPLATE 02 Chapter-by-Chapter Notes.md`
   - `00-09 Templates and Resources/01 Study Guide Templates/_TEMPLATE 03 Post-Reading Analysis.md`
5. Fill in each template with book-specific information
6. Update `00 Index.md` with the new entry

## Folder Structure

```
20-29 Literature 102/
├── 00 Index.md (this catalog)
├── README.md (this file)
├── 21 Books/
│   ├── 21.01 [Book] - [Author]/
│   │   ├── 01 Pre-Reading Guide.md
│   │   ├── 02 Chapter-by-Chapter Notes.md
│   │   └── 03 Post-Reading Analysis.md
│   ├── 21.02 [Book] - [Author]/
│   └── ... (up to 21.99)
├── 22 Supplemental Readings/ (ready for short stories, essays)
├── 23 Resources/ (ready for study materials)
└── 24 Notes and Reflections/ (ready for general notes)
```

## Study Guide Structure

Each book folder should contain three documents following the same structure as Literature 101:

- **01 Pre-Reading Guide.md** - Read before starting (overview, importance, what to think about)
- **02 Chapter-by-Chapter Notes.md** - Use while reading (important points and questions)
- **03 Post-Reading Analysis.md** - Read after finishing (in-depth exploration)

See `00-09 Templates and Resources/01 Study Guide Templates/STUDY GUIDE STRUCTURE.md` for detailed information about this system.

## Why This System?

- **Numbers stay put**: Unlike alphabetical names, numbered folders maintain their position
- **Easy to find**: Quick mental reference ("twenty-one oh two" = Fahrenheit 451)
- **Scales naturally**: Add books in any order, system accommodates growth
- **Clear organization**: Each type of material has its own category
