# Great Literature 101 - Folder Organization Guide

This folder uses the **Johnny.Decimal** system for organization. See `00 Index.md` for the complete catalog of all materials.

## Quick Start

- **Books**: Look in `11 Books/` folder
- **Short stories/Essays**: Will go in `12 Supplemental Readings/`
- **Poetry**: Will go in `13 Poetry/`
- **Resources**: Will go in `14 Resources/`
- **General notes**: Will go in `15 Notes and Reflections/`

## Adding a New Book

1. Go to `11 Books/` folder
2. Check `00 Index.md` for the next available number
3. Create folder: `11.XX [Book Title] - [Author Name]`
4. Update `00 Index.md` with the new entry
5. Start adding your notes!

## Folder Structure

```
10-19 Literature 101/
├── 00 Index.md (this catalog)
├── README.md (this file)
├── 11 Books/
│   ├── 11.01 [Book] - [Author]/
│   ├── 11.02 [Book] - [Author]/
│   └── ... (up to 11.99)
├── 12 Supplemental Readings/ (ready for short stories, essays)
├── 13 Poetry/ (ready for poetry collections)
├── 14 Resources/ (ready for study materials)
└── 15 Notes and Reflections/ (ready for general notes)
```

## Why This System?

- **Numbers stay put**: Unlike alphabetical names, numbered folders maintain their position
- **Easy to find**: Quick mental reference ("eleven oh five" = The Great Gatsby)
- **Scales naturally**: Add books in any order, system accommodates growth
- **Clear organization**: Each type of material has its own category
