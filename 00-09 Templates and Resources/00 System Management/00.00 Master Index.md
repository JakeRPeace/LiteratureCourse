## 🗂️ Available Areas for New Courses

Each new course/syllabus should get its own area (10-number range):

- **60-69:** [In Use - Southern Gothic]
- **70-79:** [In Use - Romantasy]
- **80-89:** [In Use - Biography & Autobiography]
- **90-99:** [Available]

### How to Add a New Course

1. Choose the next available area (e.g., 50-59)
2. Create folder: `50-59 Great Literature 10X - [Course Name]/`
3. Create subfolders following the standard structure:
   - `51 Books/` (or `51 Poetry/`, `51 Short Stories/`, etc.)
   - `52 Supplemental Readings/`
   - `53 Resources/`
   - `54 Notes and Reflections/`
4. Create `X0 Management/` folder (e.g. `50 Management/`)
5. Create `50.00 Index.md` in that management folder
6. Create syllabus document in that folder: `50.01 Syllabus.md`
7. Update this master index

## 📋 Standard Course Structure

Each course follows this structure:

```
[Area] Great Literature [ID] - [Course Name]/
├── [Category 0] Management/
│   ├── [Area].00 Index.md (course-specific index)
│   └── [Area].01 Syllabus.md
├── [Category 1] Books/Poetry/etc./
│   ├── [ID].01 [Item] - [Author]/
│   │   ├── 01 Pre-Reading Guide.md
│   │   ├── 02 Chapter-by-Chapter Notes.md
│   │   └── 03 Post-Reading Analysis.md
│   └── ...
├── [Category 2] Supplemental Readings/
├── [Category 3] Resources/
└── [Category 4] Notes and Reflections/
```

### Standard Categories

- **Category 1 (X1):** Primary materials (Books, Poetry Collections, etc.)
- **Category 2 (X2):** Supplemental Readings
- **Category 3 (X3):** Resources
- **Category 4 (X4):** Notes and Reflections
- **Categories 5-9 (X5-X9):** Reserved for course-specific needs

## 📖 How to Use This System

### Finding a Course
- Check this master index to see all courses
- Navigate to the course's area folder (e.g., `10-19 Great Literature 101 - Modern Literature/`)
- Check the course's `Management/[ID].00 Index.md` for detailed contents

### Adding a New Course
1. Choose next available area (50-59, 60-69, etc.)
2. Follow the standard structure
3. Copy templates from `00-09 Templates and Resources/01 Study Guide Templates/`
4. Update this master index

### Adding Materials to a Course
- Go to the course's area folder
- Follow the course's `EXPANSION GUIDE.md` or `README.md`
- Use templates from `00-09 Templates and Resources/01 Study Guide Templates/`
