# Agent Instructions

This repository follows a strict structure for literature study guides. 

## Core Rules for Agents:
1. **Templates First:** All new book documentation MUST use the templates at `00-09 Templates and Resources/01 Study Guide Templates/`.
2. **Graduate Level:** Use scholarly language. Provide deep literary analysis, not just summaries.
3. **The Three-Part System:** Every book requires a Pre-Reading Guide, Chapter-by-Chapter Notes, and a Post-Reading Analysis.
4. **Structure:** Refer to `00-09 Templates and Resources/01 Study Guide Templates/STUDY GUIDE STRUCTURE.md` for the overarching philosophy.

## Folder Management:
- Follow the Johnny.Decimal numbering system.
- Keep folders clean and standardized.
